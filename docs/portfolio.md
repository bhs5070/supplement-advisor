# 포트폴리오 소개

## 프로젝트 설명

건강기능식품의 판매 페이지에서 확인한 정보와 공식 등록정보, 조사 자료를 구분해 구매 판단의 단서를 제공하는 프로젝트다. 제품 효과나 안전성을 단정하거나 구매를 권고하는 서비스로 소개하지 않는다.

## 구현한 흐름

사용자가 제품 URL을 제출하면 공개 HTTP(S) 페이지를 안전하게 수집하고 표시 정보와 공식 등록정보를 대조한다. 결과는 PostgreSQL에 저장하며, 분석별 토큰이 있어야 조회할 수 있다. 식별 정보가 부족하면 추가 정보를 한 번 보완할 수 있다.

M2-A에서는 사용자가 근거 조사를 명시적으로 선택한다. LangGraph Supervisor가 고정된 전문 역할 중 필요한 역할을 선택하고, 공식 문서와 논문을 조사하도록 구현했다. 출처·원문 인용·조회 범위를 검증하며 비회원 개인 적합성은 미평가로 남긴다.

## 설명할 수 있는 기술적 판단

- **안전한 수집:** 내부 IP와 메타데이터 접근을 차단하고 리디렉션마다 URL·DNS와 호출 예산을 확인한다.
- **비용과 복구:** 실제 외부 요청 전에 예약하고 상태를 저장한다. claim·lease가 유효한 Worker만 결과를 갱신한다. 결과가 불명확한 요청은 자동 반복하지 않는다.
- **근거의 범위:** 검색 결과와 읽은 초록·본문을 구분한다. 일반 원료 자료를 완제품 효과의 증명으로 확대하지 않는다.
- **검증 과정:** 구현자와 검토자를 분리하고, 발견한 오류를 재현한 뒤 수정·재검토했다. 실제 연동과 모의 테스트를 구분해 기록했다.

## 기술 구성

React·TypeScript·Vite, FastAPI, Celery·Redis, PostgreSQL·SQLAlchemy, HTTPX, LangGraph를 사용한다. OpenAI 모델과 식품안전나라·자료 검색 연동을 사용하며, 키가 없을 때는 미설정 상태를 반환한다. 설치·실행 방법은 저장소 README에 있다.

## 검증과 한계

M1은 한정된 실제 URL의 수집·공식 대조·저장·권한 조회와 보완 흐름을 확인했다. 모든 사이트에서 안정적인 자동 추출이나 높은 매칭 정확도를 입증한 것은 아니다.

M2-A의 마지막 필수 수정 전 후보는 실제 PostgreSQL을 포함한 전체 검사 342 passed/4 skipped, Chromium API fixture 검사 26 passed/22 project-filter skips를 기록했다. 이후 필수 수정은 관련 검사 90 passed/5 PostgreSQL 조건 skips와 카운터 회귀 검사, 독립 재검토를 통과했다. 앞선 전체 검사 수치를 마지막 수정본의 전체 통과 결과로 사용하지 않는다.

마지막 수정본의 전체 실PG 재검증, 실행 반영, 새 URL의 실제 모델·자료 조회 검증은 남아 있다. 제품 점수·구매 추천·회원 개인화도 후속 범위다. 현재 결과는 [검증 기록](verification.md)과 [최종 검토](reviews/m2a-review.md)에 연결한다.

## 짧은 소개 문구

> URL 기반 건강기능식품 근거 조사 도구를 개발했습니다. LangGraph의 역할 선택과 자료 조사 흐름에 SSRF 방어, 호출 예산, Worker 복구, 토큰 기반 조회 권한을 연결했습니다. M1의 한정 실연동을 검증했고, M2-A는 구현·독립 검토 후 최종 실연동 검증을 남겨 두고 있습니다.
